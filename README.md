# AI-Based Brute Force Attack Detection System

## Project Overview
A Python-based cybersecurity mini project that uses Machine Learning to identify suspicious login activities and detect potential brute force attacks through simulated authentication data.

## Objectives
- Simulate normal and suspicious login attempts.
- Analyse login patterns and failed attempts.
- Detect potential brute force attacks using Machine Learning.
- Improve authentication security awareness.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- CSV
- Visual Studio Code

## Features
- Normal login simulation.
- Brute force attack simulation.
- Login history tracking.
- IP address monitoring.
- AI-based threat classification.
- Suspicious activity alerts.

## Project Files
- `Bruteforcedetector.py` – Main Python program.
- `login_history.csv` – Login activity dataset.

## Installation and Execution

Install the required libraries:

```bash
pip install numpy pandas scikit-learn
```

Run the program:

```bash
python Bruteforcedetector.py
```
